# Widget Windows DumbFuckCockpit

## Télécharger et installer

1. Téléchargez le fichier **DumbFuckCockpit-Widget-…-x64.exe** et enregistrez-le dans **Téléchargements**.
2. Double-cliquez sur le fichier téléchargé. L’installation se fait automatiquement dans le dossier des applications Windows.
3. L’installation crée un seul raccourci **DumbFuckCockpit Widget** sur le Bureau et démarre le widget.
4. Fermez la fenêtre du site web pour voir le widget seul sur le bureau.

Vous n’avez pas à choisir un dossier d’installation, à extraire des fichiers ni à garder le fichier téléchargé sur le Bureau. Les fichiers nécessaires restent dans le dossier Windows des applications; seul le raccourci apparaît sur le Bureau.

## Site web ou widget ?

- **Site web :** cockpit complet et interactif pour ouvrir les menus et gérer les tâches.
- **Widget Windows :** visuel animé et transparent sur le bureau. Il laisse passer les clics vers les icônes Windows.
- **N’ouvrez pas les deux pour faire fonctionner le widget.** Lancez le widget seul; ouvrez le site seulement quand vous voulez utiliser ses menus.
- Le visuel vient du même projet. Les tâches enregistrées dans le site ne sont pas synchronisées avec le widget.

Pour les réglages, double-cliquez de nouveau sur le raccourci du Bureau pendant que le widget fonctionne. Fermer le panneau laisse le widget actif.

## Mise à jour

Le widget contient une copie des fichiers du site au moment de la publication. Pour obtenir un nouveau visuel publié, téléchargez et installez la nouvelle version Windows. Les données du site restent dans le navigateur.

L’application cible Windows 10 et Windows 11. L’installateur n’est pas signé; Windows peut afficher un avertissement d’éditeur non vérifié.
